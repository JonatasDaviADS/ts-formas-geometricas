# Formas Geométricas — TypeScript

Calcula a área de formas geométricas usando classe abstrata, herança e polimorfismo.

## Classes
| Classe | Fórmula |
|---|---|
| `Forma` (abstrata) | `CalcularArea()` |
| `Quadrado` | `lado²` |
| `Retangulo` | `base × altura` |
| `Triangulo` | `(base × altura) / 2` |
| `Circulo` | `π × raio²` |

## Como rodar
```bash
npm install
npm run build
npm start
```

## Resultado
```
Quadrado: área = 16.00
Retângulo: área = 15.00
Triângulo Retângulo: área = 12.00
Círculo: área = 12.57
```
